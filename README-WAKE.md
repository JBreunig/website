# Wake Forest redesign

This branch contains the first-pass redesign of the Breunig Lab website for Wake Forest University School of Medicine.

## Current scope
- New Wake Forest / Department of Cancer Biology identity
- Modernized homepage using existing lab imagery
- Updated research framing based on the current Breunig Lab program
- Custom styling for desktop and mobile
- Custom domain prepared for `breuniglab.com`

The existing `master` branch and current site remain unchanged until this redesign is reviewed and merged.
